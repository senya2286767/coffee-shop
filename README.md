# ☕ Веб-приложение кофейни «Тёплое место»

Полнофункциональное веб-приложение интернет-магазина кофейни с акцентом на современный UI/UX-дизайн, адаптивную верстку и интерактивные элементы. 

Проект разработан в рамках учебной практики. Основная особенность — уникальная система кастомизации напитков с помощью Drag-and-Drop стикеров.

## Основной функционал

### Для клиента (Пользователя):
*   **Каталог товаров:** Просмотр товаров, фильтрация по категориям, пагинация.
*   **Карточка товара:** Детальная информация (состав, КБЖУ, объем, тип молока), выбор опций.
*   **Корзина:** 
    *   Уникальная логика хранения (один и тот же напиток с разными стикерами считается разными позициями).
    *   Асинхронное изменение количества товаров (AJAX) без перезагрузки страницы.
*   **Оформление заказа:** Ввод контактных данных, выбор способа получения.
*   **Генерация чеков:** Автоматическое создание PDF-чека после оформления заказа (с поддержкой кириллицы).
*   **Регистрация и авторизация:** Личный кабинет клиента с историей заказов.
*   **Блог:** Просмотр статей и новостей кофейни.

### Для администратора:
*   **Управление контентом:** Встроенная админ-панель Django для управления товарами, категориями, блогом и пользователями.
*   **Дашборд со статистикой:** Кастомная страница аналитики с визуализацией данных (график выручки за 7 дней на Chart.js, таблица последних заказов).

### Особенности:
*   **Drag-and-Drop стикеры:** Интерактивная страница, где пользователь может перетаскивать стикеры на изображение стакана. Выбранные стикеры сохраняются в заказе.
*   **Умная корзина:** Ключи в сессии формируются как `ID_Стикеры` (например, `1_Тепло,Кофе`), что позволяет разделять одинаковые напитки с разной кастомизацией.

## Стек технологий
*   **Backend:** Python 3, Django
*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS Variables), Vanilla JavaScript (Fetch API, HTML5 Drag and Drop)
*   **База данных:** SQLite (по умолчанию)
*   **Библиотеки:** 
    *   `Pillow` (работа с изображениями)
    *   `xhtml2pdf` (генерация PDF-чеков)
    *   `Chart.js` (визуализация графиков)

## Установка и запуск проекта

Для запуска проекта на локальном компьютере выполните следующие шаги:

### 1. Клонирование репозитория
```bash
git clone https://github.com/ваш-логин/coffee-shop.git
cd coffee-shop
```

---

### 2. Создание и активация виртуального окружения
**Windows:**
```bash
python -m venv venv
.\venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Если файла requirements.txt нет, установите вручную: `pip install django pillow xhtml2pdf`)*

### 4. Применение миграций (создание базы данных)
```bash
python manage.py migrate
```

### 5. Создание суперпользователя (для входа в админку)
```bash
python manage.py createsuperuser
```
*(Придумайте логин, email и пароль)*

### 6. Запуск сервера
```bash
python manage.py runserver
```

После этого проект будет доступен по адресу: http://127.0.0.1:8000/

│   └── core/
│       ├── base.html       # Базовый шаблон (шапка, подвал)
│       ├── index.html      # Главная страница

│   ├── css/                # Стили (globals.css, style.css)
